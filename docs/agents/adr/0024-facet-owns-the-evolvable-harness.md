# Let the facet own the harness it runs, and contain only the supervisor's recovery authority

The facet is the mutable active agent: its model loop, tools, prompts, policies, modules, and work environment are all things a generation is allowed to change, because none of them can undo a promotion or a rollback. `read`, `write`, `edit`, and `bash` are today's bootstrap action space, not a permanent ceiling — ADR-0004 and ADR-0020 froze that bootstrap into an invariant and are gone. A broad facet-owned workspace, a native runtime, or a redesigned tool set is not by itself a containment breach; the only thing the boundary has to stop is a facet reaching supervisor authority — the generation registry, materialization records, validation evidence, the live pointer, rollback, and genesis recovery — outside a sanctioned control path such as a promotion request the supervisor validates and attests itself. Evaluating a candidate's capability breadth by counting its tools was never the right test; the right test is whether that capability lets it touch recovery directly, and everything else is ordinary work the facet is free to redesign.

## Consequences

This retires the four-primitive shim and the WASM-shell prohibition as fixed points: a future generation may add tools, run a different loop, or ask for a fuller workspace, and none of that needs a new ADR unless it changes what can reach supervisor authority. What still needs one is any change to the sanctioned control paths themselves — promotion, rollback, attestation, and the transaction boundary in ADR-0003 — because those are the actual containment boundary this decision protects.
