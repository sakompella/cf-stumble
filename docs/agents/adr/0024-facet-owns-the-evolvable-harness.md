# Let the facet own the harness it runs, and contain only the supervisor's recovery authority

The facet is the mutable active agent: a generation may change its model loop, tools, prompts, policies, modules, runtime, and work environment. `read`, `write`, `edit`, and `bash` are the bootstrap action space, not a permanent ceiling. A broad facet-owned workspace, a native runtime, or a redesigned tool set is not itself a containment breach; the boundary must prevent the facet from reaching supervisor authority — the generation registry, materialization records, validation evidence, live pointer, rollback, and genesis recovery — outside sanctioned requests that the supervisor validates and executes itself. Capability breadth is judged by whether it compromises independent recovery, not by counting tools.

## Consequences

The bootstrap tool registry and current shell are implementation choices that later generations may replace. Changes to sanctioned supervisor paths — candidate submission, promotion, rollback, attestation, and the transaction boundary in ADR-0003 — require separate review because those paths form the containment boundary.
