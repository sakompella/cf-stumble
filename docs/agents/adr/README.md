# Architecture decisions

Current decisions only. Each ADR's `> **Review:**` line says whether Aditya approved it (`Human-approved`) or an agent recorded it without his review (`Agent-only`). Read the human-approved ones first; they win when the two conflict.

Add an ADR only for a decision that is expensive to reverse, had a real alternative, and would surprise a reader of the code. Keep it short. When a decision no longer applies, delete its ADR; Git keeps the history.
