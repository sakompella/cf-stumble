# Architecture decisions

This directory records current decisions. Every ADR declares whether a human approved it or an agent recorded it without human approval, on its `> **Review:**` line. Read the human-approved decisions first: they take precedence over agent-only records when the two conflict. When a decision no longer applies, delete its ADR; Git retains the historical record.

Add an ADR only for a decision that is expensive to reverse, has a real alternative, and would surprise a reader of the code. Keep it short.
