# Use replay as an executor-compatibility ratchet

Replay recorded model responses against the actual candidate facet, not a frozen surrogate, to check that it still produces the taped tool calls and workspace effects for that protocol version. A tape cannot say whether a changed prompt is better: it came from the old prompt, so it would approve a prompt-only change without exercising it. Promotion rejects regressions from the live generation and separately requires supervisor-pinned canaries to pass. Prompt-quality evaluation needs fresh, scored trials and remains a separate future mechanism. A tape applies to the protocol version it was recorded under, so a facet that changes its tools, prompts, or loop needs a tape for that shape instead of being blocked by one that predates it. The ratchet checks compatibility within a version; it does not require the version never to change.
