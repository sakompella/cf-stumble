# Status: 2026-10-02

Read this after `docs/agents/domain.md`'s required order. It records what changed since
`docs/agents/status-2026-09-27.md`, what runs in production, which facts were verified and how, and
what is still open. It is a snapshot at `main` `4636cc5` (2026-10-02). It does not replace an ADR or
a design document. The 09-27 snapshot stays as history; read it for the `v0`-to-09-26 changes.

## Baseline

`main` was at `4636cc5` ("fix(ops-check): match restart requests against all fetched logs"). The
09-27 snapshot was written at `eafaf99`; 354 commits separate `v0` from this head. `pnpm verify`
passes at every commit since `e4b753b`: the idle-stop series was rebuilt so that each commit builds
on its own, and a `git rebase -x "pnpm verify"` run proved it.

## What changed since 2026-09-27, by area

Dates are the commit dates in `git log`. Some commits carry a later date than the work, because
history was rewritten once so that each commit passes the gate.

- **Cost incident and its fixes.** A $10.25 invoice and 18-hour container runs on 09-26 and 09-27
  led to four root causes and four fixes. See `docs/agents/incident-2026-09-container-cost.md`.
- **Runtime observability (`71f03be` to `f8b03b3`, 2026-09-30).** Container launch, adoption, and
  stop events from the platform's own results; a server-made `requestId` on every route that
  touches the workspace; `route.settled`; timed credential status reads. Documented in
  `docs/agents/design/observability.md`.
- **Move to the `cf` CLI (`46a2210` to `ac54e4c`, 2026-09-30).** `cloudflare.config.ts` is now the
  source of truth for the Worker. Durable Objects are declared with `worker.exports` instead of
  `migrations`. Wrangler 4.145 is the pinned version. A drift test keeps `wrangler.jsonc` and
  `wrangler.test.jsonc` equal to the new file. See `docs/deploy.md`, "Configuration files".
- **Traces and Issues (`c0816a9`, `a706b75`, `288bc30`, `8f0a8da`, 2026-09-30).** Traces and
  Cloudflare Issues are enabled with every sampling rate at 1. An `owner-api.route` span carries
  `request.id`, and `route.settled` logs at `error` when a request held the workspace for a full
  command budget, so Issues sees it.
- **Instance secrets (`bae9d41`, `c107d59`, `e06096f`).** Per-instance values are Worker secrets
  that no config file declares. `docs/deploy.md`, "Instance secrets", has the rules.
- **Build output to the owner (`a8d3597`, `8e1b1bd`, `2e3e5e3`, `6a7906e`).** A failed build step
  no longer writes its stdout and stderr to the log. The redacted tail (2,000 UTF-16 code units per
  stream) travels in the submission response and the owner page shows it in a collapsed panel.
- **Durable GitHub credential (`3adf75c` to `fad987a`).** `gh` and Git global configuration now
  live under `/workspace`, so the GitHub connection survives a container replacement. The root
  cause was in `docs/agents/design/github-connection.md`, "Where the credential lives".
- **Idle stop (`0521455` to `281f2bb`, ADR-0043).** The Workspace Host stops its container after ten
  minutes with no workspace work. `53366fb` and `58b8d26` (ADR-0044) lowered the shim's disk walk
  from every 250 ms to every 5 s and capped the setting.
- **`pnpm ops:check` (`94ef17c` to `4636cc5`).** A read-only command that applies nine rules to a
  window of logs, container metrics, and running instances. It is in
  `docs/agents/design/observability.md`, "Checking a running deployment".

  `trigger: idle-stop`, `workspace.container.stopped` carried `reasonCode: idle-stop` and

- **`request.id` finds a trace.** The filter `request.id = <id>` returns the `owner-api.route` span,

## Decisions recorded today

- **Keep the second `monitor()` call.** The stop observer calls the platform's `monitor()` after
  Computer's own call. The platform documents that a pending `monitor()` can keep the Durable Object
  in memory for up to 15 minutes. The extra residency was never measured. The owner accepted that
  small cost for the stop events. An external accounting design was considered and set aside.
- **Skip Cloudflare Artifacts for now.** See `docs/agents/design/computer-integration.md`,
  "Artifacts (deferred)".
- **Per-instance values are secrets that no file declares.** A declared secret is required, which
  would make the first deploy of a new Worker fail. See `docs/deploy.md`, "Instance secrets".
- **The idle stop and the 5 s poll** have their own ADRs (ADR-0043, ADR-0044).

## Open items

1. **Flaky test.** `test/github/repository-size-guard.props.test.ts` times out at 5 s under load. It
   passes when the machine is quiet. It needs its own fix.
2. **Early platform stops with an unknown reason.** On 2026-10-02 the container stopped after a
   transport close while `running` was `true`, at about 16:03Z, 16:32Z, and 21:25Z. At 21:25Z the
   stop came 48 s after the last work, and the idle alarm had not fired. These are not Host stops.
   Their cause is unverified. `ops:check` reports them as `running-close` and `unexplained-stop`.
3. **First turn after an idle stop.** The Host marks the next connect as not a replacement
   (`ContainerLifecycle.stoppedByHost`), so the first project exec should not report
   `container-restarted`. This is unit-tested only. Check it on staging: stop the container with
   the idle alarm, then run a project exec through a fresh `project()` capability.
4. **Process accounting (observability plan step 3b).** Not built. The 09-27 CPU source is
   explained (the shim walk), so this has lower priority. See the incident record.
5. **Artifacts checkpoint pilot.** Deferred; it needs owner approval of a new paid product.
6. **Registry images.** About 14 old images of `cf-stumble-workspacehost` remain as rollback
   history. Delete them with `wrangler containers images delete` when a rollback to them is no
   longer wanted.
7. **Stale worktrees.** About 45 linked worktrees under `../.worktrees` come from older sessions.
   `git worktree list` shows them. Remove the ones whose branches are merged.
