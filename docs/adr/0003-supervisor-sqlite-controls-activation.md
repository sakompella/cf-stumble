# Keep activation authority in supervisor SQLite

The generation registry, live pointer, activation ledger, validation records, corpus, and accumulated context belong to the supervisor Durable Object's SQLite database; promotion changes its authority rows in one `transactionSync()` transaction with a compare-and-swap check. Git refs, Workers KV, and a workspace filesystem may hold content or caches, but none can decide what is live because they sit outside that transaction and could expose a torn state. Keeping corpus and context outside generations also means rollback never rewinds the evidence used to judge it.
