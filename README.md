# cf-stumble

An incomplete project!

This project aims to build an Orbstack-like experience to the user using Cloudflare's primatives, notably Workers, Durable Object, and Dynamic Workers. I aim to publish a full (hand written!) rationale later on project completion. The goal is to build an extensible harness that allows the user to modify with the harness similar to Pi or Autolith, but in the cloud allowing for multi-person multi-project prompting.

Some parts of other documentation files is incomplete, out of date, or otherwise wrong. I am in the process of cleaning it up, and I appologize.
